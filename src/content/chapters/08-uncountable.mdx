## 並べられない無限

第7章では、$\mathbb{N}$、$\mathbb{Z}$、$\mathbb{Q}$ がすべて同じ濃度であることを見ました。こうなると、「無限集合はどれも可算なのでは？」と思えてきます。この章では、その予想が**間違っている**ことを証明します。

<Definition label="定義 8.1" title="非可算集合">
高々可算でない集合（有限でも可算無限でもない集合）を**非可算集合**という。
</Definition>

## 小数表示の準備

証明では、実数の小数表示を使います。その前に、注意しておくことがあります。

$$
0.1000\cdots = 0.0999\cdots
$$

は**同じ数**です（$0.0999\cdots = 0.09 + 0.009 + \cdots = \frac{0.09}{1 - 0.1} = 0.1$）。このように、小数表示は1通りとは限りません。

<Theorem label="事実 8.2" title="標準的な小数表示">
$0 \le x < 1$ を満たす実数 $x$ は、

$$
x = 0.d_1 d_2 d_3 \cdots \qquad (d_n \in \{0, 1, \dots, 9\})
$$

と表せる。さらに「ある桁から先がすべて 9 になる」表示を除くと、この表し方は**ただ1通り**である。この表示を $x$ の**標準的な小数表示**と呼ぶ。
</Theorem>

これは実数の連続性（第6章）から証明できる事実ですが、このサイトでは証明せずに使います。大事なのは次の点です。

- 末尾が 9 の連続になる表示を除けば、**2つの実数が等しいことと、標準的な小数表示がすべての桁で一致することは同じ**。
- 標準的な小数表示が1桁でも違えば、2つの実数は異なる。

## カントールの対角線論法

<Theorem label="定理 8.3" title="カントール">
区間 $[0, 1)$ は非可算である。
</Theorem>

まず、証明のアイデアを下の図で見てみましょう。

<DiagonalArgument client:visible />

<Proof>
$[0, 1)$ は無限集合なので、可算でないことを示せば十分です。背理法で、$[0, 1)$ が可算であると仮定します。すると、全単射（特に全射）$f \colon \mathbb{N} \to [0, 1)$ が存在し、$[0, 1)$ の要素をすべて

$$
x_1 = f(1),\quad x_2 = f(2),\quad x_3 = f(3),\quad \dots
$$

と並べられます。各 $x_n$ の**標準的な小数表示**を

$$
x_n = 0.d_{n1}\, d_{n2}\, d_{n3} \cdots
$$

とします（$d_{nk}$ は $x_n$ の小数第 $k$ 位の数字）。

ここで、新しい数 $c = 0.c_1 c_2 c_3 \cdots$ を、各桁を

$$
c_n = \begin{cases} 2 & (d_{nn} = 1) \\ 1 & (d_{nn} \ne 1) \end{cases}
$$

と定めて作ります。

**$c$ は $[0, 1)$ の要素である。** 各桁は 1 か 2 なので、$0 < c < 1$ です。

**この表示は $c$ の標準的な小数表示である。** $c$ の各桁は 1 か 2 で、9 は1つも現れません。したがって「ある桁から先がすべて 9」という表示ではないので、これが $c$ の標準的な小数表示です。

**$c$ はどの $x_n$ とも異なる。** どの $n$ についても、$c$ の第 $n$ 位 $c_n$ と $x_n$ の第 $n$ 位 $d_{nn}$ は異なります（$d_{nn} = 1$ なら $c_n = 2$、そうでなければ $c_n = 1$）。$c$ と $x_n$ はどちらも標準的な小数表示で書かれているので、事実 8.2 の一意性より、$c \ne x_n$ です。

以上より $c \in [0, 1)$ ですが、$c$ はリスト $x_1, x_2, \dots$ のどれとも等しくありません。これは $f$ が全射であることに矛盾します。よって $[0, 1)$ は非可算です。
</Proof>

<Pitfall title="なぜ 0 と 9 を避けるのか">
もし「$d_{nn}$ に 1 を足す（9 なら 0 にする）」というルールで $c$ を作ると、たとえば $c = 0.1000\cdots$ と $x_n = 0.0999\cdots$ のように、**表示は違うのに同じ数**になってしまう可能性があります。そうなると「1桁違うから異なる数」という議論が成り立ちません。

上の証明では、$c$ の桁に 1 と 2 しか使わないことで、$c$ の表示が標準的なものであることを保証しています。さらに $x_n$ も標準的な表示で書いているので、「表示が違えば数も違う」と言えるのです。証明の細かい部分に見えますが、ここを省くと証明に穴があきます。
</Pitfall>

<Theorem label="系 8.4">
実数全体 $\mathbb{R}$ は非可算である。
</Theorem>

<Proof>
$\mathbb{R}$ が高々可算だとすると、その部分集合 $[0, 1)$ も高々可算になります（高々可算集合から $\mathbb{N}$ への単射を $[0,1)$ に制限すれば単射のまま。定理 7.6）。これは定理 8.3 に矛盾します。
</Proof>

<Theorem label="系 8.5">
無理数全体 $\mathbb{R} \setminus \mathbb{Q}$ は非可算である。
</Theorem>

<Proof>
無理数全体が高々可算だとすると、$\mathbb{R} = \mathbb{Q} \cup (\mathbb{R} \setminus \mathbb{Q})$ は「可算集合」と「高々可算集合」の和で、高々可算になります（具体的な列挙を交互に並べればよい）。これは系 8.4 に矛盾します。
</Proof>

数直線の上で、有理数はびっしり詰まっているように見えます。それでも、**数としては無理数のほうが圧倒的に多い**のです。同様に、第7章の演習問題 7.4 で見た代数的数は可算なので、代数的数でない実数（**超越数**、$\pi$ や $e$ など）も非可算個あります。

<Quiz id="uncountable-q01">
対角線論法を有理数全体 $\mathbb{Q} \cap [0, 1)$ のリストに当てはめると、リストにない数 $c$ が作れる。それでも「$\mathbb{Q}$ は非可算」とはならない理由は？

<Choice>有理数は小数で表せないから</Choice>
<Choice correct>作った $c$ が有理数とは限らず、$\mathbb{Q}$ のリストに載っていなくても矛盾しないから</Choice>
<Choice>有理数のリストは有限だから</Choice>
<Choice>対角線上の数字が決まらないから</Choice>

<Explain>
対角線論法で作った $c$ は、確かに $[0, 1)$ の実数で、リストのどの数とも異なります。しかし $c$ が**有理数**である保証はありません（実際、$\mathbb{Q} \cap [0, 1)$ のリストから作った $c$ は必ず無理数になります。もし有理数なら、リストのどこかに載っているはずだからです）。「$\mathbb{Q}$ のリストに載っていない無理数がある」ことは何の矛盾でもないので、証明は成り立ちません。対角線論法で矛盾が出るのは、作った数が**リストに載っているべき集合の要素である**ことが保証されているときだけです。
</Explain>
</Quiz>

## 濃度の大小

非可算集合があると分かったので、濃度の「大小」を定義しましょう。

<Definition label="定義 8.6" title="濃度の大小">
- $A$ から $B$ への単射が存在するとき、$\lvert A \rvert \le \lvert B \rvert$ と書く。
- $\lvert A \rvert \le \lvert B \rvert$ かつ $\lvert A \rvert \ne \lvert B \rvert$（全単射は存在しない）のとき、$\lvert A \rvert < \lvert B \rvert$ と書く。
</Definition>

「$A$ の要素を、$B$ の異なる要素に1つずつ割り当てられる」ことを、「$A$ は $B$ 以下」と定めるわけです。

<Example>
- $A \subseteq B$ ならば、包含写像 $a \mapsto a$ が単射なので $\lvert A \rvert \le \lvert B \rvert$。
- $\lvert \mathbb{N} \rvert < \lvert \mathbb{R} \rvert$：$\mathbb{N} \subseteq \mathbb{R}$ なので $\le$、系 8.4 より全単射はない。
</Example>

<Note title="記号 ≤ に期待すること">
記号 $\le$ を使う以上、数の大小と同じ性質を持っていてほしいところです。反射律（$\lvert A \rvert \le \lvert A \rvert$）と推移律（単射の合成は単射）はすぐに分かります。しかし反対称律、つまり

$$
\lvert A \rvert \le \lvert B \rvert \text{ かつ } \lvert B \rvert \le \lvert A \rvert \implies \lvert A \rvert = \lvert B \rvert
$$

は自明ではありません。単射が両方向にあることから、全単射を**作る**必要があるからです。これが次の章の**カントール＝ベルンシュタイン＝シュレーダーの定理**です。
</Note>

## カントールの定理

対角線論法のアイデアは、実数だけでなく、**どんな集合**にも使えます。

<Theorem label="定理 8.7" title="カントールの定理">
どんな集合 $A$ についても、$\lvert A \rvert < \lvert \mathcal{P}(A) \rvert$ である。
</Theorem>

<Proof>
**$\lvert A \rvert \le \lvert \mathcal{P}(A) \rvert$：** $a \mapsto \{a\}$ は $A$ から $\mathcal{P}(A)$ への写像で、$\{a\} = \{b\} \Rightarrow a = b$ なので単射です。

**全単射が存在しないこと：** 任意の写像 $f \colon A \to \mathcal{P}(A)$ が**全射でない**ことを示します（全射でなければ、もちろん全単射でもありません）。各 $a \in A$ について $f(a)$ は $A$ の部分集合なので、「$a \in f(a)$ か、$a \notin f(a)$ か」のどちらかです。そこで

$$
D = \{\, a \in A \mid a \notin f(a) \,\}
$$

とおきます。$D \subseteq A$ なので $D \in \mathcal{P}(A)$ です。

$D = f(d)$ となる $d \in A$ があると仮定してみます。

- $d \in D$ ならば、$D$ の定義より $d \notin f(d) = D$。矛盾。
- $d \notin D$ ならば、$d \notin f(d)$ なので、$D$ の定義より $d \in D$。矛盾。

どちらの場合も矛盾するので、$D = f(d)$ となる $d$ は存在しません。つまり $D$ には何も移らず、$f$ は全射ではありません。
</Proof>

<Idea title="これも対角線論法">
分かりやすくするため、$A$ が可算で $A = \{a_1, a_2, a_3, \dots\}$ と並べられる場合を考えます。「$a_i \in f(a_j)$ なら 1、そうでなければ 0」という表を作ります。行が $f(a_1), f(a_2), \dots$ に、列が $a_1, a_2, \dots$ に対応します。

| | $a_1$ | $a_2$ | $a_3$ | $\cdots$ |
| --- | :-: | :-: | :-: | :-: |
| $f(a_1)$ | **1** | 0 | 1 | |
| $f(a_2)$ | 0 | **0** | 1 | |
| $f(a_3)$ | 1 | 1 | **1** | |
| $\vdots$ | | | | |

$D$ は、この表の**対角線を 0 と 1 で反転**したもの（上の例なら「$a_1$ を含まない、$a_2$ を含む、$a_3$ を含まない、…」）です。だから $D$ は、どの行 $f(a_j)$ とも $a_j$ の列で食い違います。実数の対角線論法と同じ構造です。
</Idea>

<Theorem label="系 8.8" title="最大の無限は存在しない">
$$
\lvert \mathbb{N} \rvert < \lvert \mathcal{P}(\mathbb{N}) \rvert < \lvert \mathcal{P}(\mathcal{P}(\mathbb{N})) \rvert < \cdots
$$

どんな集合に対しても、それより真に大きい濃度を持つ集合が存在する。
</Theorem>

無限には大きさの違いがあり、しかも**いくらでも大きな無限がある**。これが、カントールが発見した驚くべき事実です。

<Quiz id="uncountable-q02">
$A = \{1, 2, 3\}$、$f \colon A \to \mathcal{P}(A)$ を $f(1) = \{1, 2\}$、$f(2) = \{3\}$、$f(3) = \{1, 3\}$ とする。カントールの定理の証明の集合 $D = \{\, a \in A \mid a \notin f(a) \,\}$ は？

<Choice>$\varnothing$</Choice>
<Choice correct>$\{2\}$</Choice>
<Choice>$\{1, 3\}$</Choice>
<Choice>$\{3\}$</Choice>

<Explain>
$1 \in f(1) = \{1, 2\}$ なので $1 \notin D$。$2 \notin f(2) = \{3\}$ なので $2 \in D$。$3 \in f(3) = \{1, 3\}$ なので $3 \notin D$。よって $D = \{2\}$ です。実際、$\{2\}$ は $f(1), f(2), f(3)$ のどれとも異なり、$f$ が全射でないことが確かめられます。
</Explain>
</Quiz>

<Note title="連続体仮説">
$\lvert \mathbb{N} \rvert < \lvert \mathbb{R} \rvert$ ですが、その**間の濃度**を持つ集合はあるのでしょうか？ 「ない」という予想を**連続体仮説**といいます。カントールはこれを証明しようとして果たせませんでした。20 世紀になって、ゲーデルとコーエンの研究により、連続体仮説は通常の集合論の公理（ZFC）からは**証明も反証もできない**こと（ZFC が矛盾しない限り）が分かりました。第10章で、この「公理」の話に触れます。
</Note>

## 演習問題

<Exercise level={1} label="問 8.1">
次の集合は、可算か非可算か答えよ。理由も簡単に述べよ。

1. $\mathbb{Q} \times \mathbb{Q}$
2. 区間 $(2, 3)$
3. $\mathbb{N}$ の有限部分集合全体
4. $\mathcal{P}(\mathbb{N})$

<Reveal>
1. 可算。$\mathbb{Q}$ が可算なので、$\mathbb{N} \times \mathbb{N}$ と同様に可算です。
2. 非可算。$x \mapsto x - 2$ は $(2, 3)$ から $(0, 1)$ への全単射で、$(0, 1) = [0, 1) \setminus \{0\}$ は非可算です（可算なら、$\{0\}$ を加えた $[0,1)$ も可算になってしまう）。
3. 可算。要素の個数が $k$ の部分集合全体を $F_k$ とすると、$F_k$ は $\mathbb{N}^k$ への単射（要素を小さい順に並べる）を持つので高々可算で、具体的に列挙できます。$\bigcup_k F_k$ なので可算です。（別解：$\{n_1, \dots, n_k\} \mapsto 2^{n_1} + \cdots + 2^{n_k}$ は単射。）
4. 非可算。カントールの定理より $\lvert \mathbb{N} \rvert < \lvert \mathcal{P}(\mathbb{N}) \rvert$。
</Reveal>
</Exercise>

<Exercise level={2} label="問 8.2">
0 と 1 だけからなる無限列 $(s_1, s_2, s_3, \dots)$ 全体の集合 $\{0, 1\}^{\mathbb{N}}$ が非可算であることを、対角線論法で直接示せ。

<Reveal>
可算だと仮定し、すべての列を $s^{(1)}, s^{(2)}, s^{(3)}, \dots$ と並べます（$s^{(n)} = (s^{(n)}_1, s^{(n)}_2, \dots)$）。新しい列 $t$ を $t_n = 1 - s^{(n)}_n$ で定めます。$t$ は 0 と 1 からなる無限列ですが、どの $n$ についても $t_n \ne s^{(n)}_n$ なので、$t \ne s^{(n)}$ です。これはリストがすべての列を含むことに矛盾します。

（今回は「列」そのものを比べるので、小数表示のような一意性の問題は起こりません。列は、各項がすべて一致するときに限り等しいからです。）
</Reveal>
</Exercise>

<Exercise level={2} label="問 8.3">
$\lvert \{0, 1\}^{\mathbb{N}} \rvert = \lvert \mathcal{P}(\mathbb{N}) \rvert$ であることを示せ。

<Reveal kind="hint">
部分集合 $S \subseteq \mathbb{N}$ に、「$n \in S$ なら 1、そうでなければ 0」という列を対応させます（**特性関数**）。
</Reveal>

<Reveal>
$S \subseteq \mathbb{N}$ に列 $\chi_S = (\chi_S(1), \chi_S(2), \dots)$、$\chi_S(n) = 1$（$n \in S$）、$\chi_S(n) = 0$（$n \notin S$）を対応させます。

- 単射：$S \ne T$ なら、どちらか一方だけに属する $n$ があり、$\chi_S(n) \ne \chi_T(n)$。
- 全射：列 $s$ に対して $S = \{\, n \mid s_n = 1 \,\}$ とおけば $\chi_S = s$。

よって全単射です。問 8.2 と合わせると、これもカントールの定理（$A = \mathbb{N}$ の場合）の証明になっています。
</Reveal>
</Exercise>

<Exercise level={3} label="問 8.4">
カントールの定理の証明で、$D = \{\, a \in A \mid a \notin f(a) \,\}$ の代わりに $E = \{\, a \in A \mid a \in f(a) \,\}$ を使うと、証明はうまくいくか。うまくいかないなら、どこで失敗するか説明せよ。

<Reveal>
うまくいきません。$E = f(e)$ となる $e$ があると仮定すると、

- $e \in E$ ならば $e \in f(e) = E$ で、矛盾しない。
- $e \notin E$ ならば $e \notin f(e) = E$ で、矛盾しない。

どちらの場合も矛盾が出ないので、「$E$ には何も移らない」とは言えません。実際、$A = \{1\}$、$f(1) = \{1\}$ とすると $E = \{1\} = f(1)$ となり、$E$ は $f$ の値域に入っています。

$D$ がうまくいくのは、「$a \notin f(a)$」という**否定**によって、$D$ が各 $f(a)$ と必ず食い違うように作られているからです。対角線を「反転」することが本質です。
</Reveal>
</Exercise>

## まとめ

- 実数の区間 $[0, 1)$ は**非可算**。リストを仮定し、対角線上の桁を変えた数を作って矛盾を導く（**対角線論法**）。
- 小数表示は一意でないので、**標準的な表示を使い、作る数の桁を 1 と 2 に限る**ことで穴をふさぐ。
- $\mathbb{R}$、無理数全体、超越数全体は非可算。
- $\lvert A \rvert \le \lvert B \rvert$ は「単射 $A \to B$ がある」こと。
- **カントールの定理**：$\lvert A \rvert < \lvert \mathcal{P}(A) \rvert$。最大の無限は存在しない。

次の章では、「単射が両方向にあれば全単射がある」という、濃度を比べるうえで欠かせない定理を証明します。
