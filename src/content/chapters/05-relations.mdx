## 関係とは

「$<$」「$=$」「割り切る」「同じクラスに所属する」のように、2つのものの間に成り立つか成り立たないかが決まる性質を**関係**といいます。

<Definition label="定義 5.1" title="関係">
集合 $X$ 上の**関係**とは、直積 $X \times X$ の部分集合 $R$ のことである。$(a, b) \in R$ のとき $a \mathrel{R} b$ と書き、「$a$ と $b$ は関係 $R$ にある」という。
</Definition>

関係を「部分集合」として定義するのは不思議に思えるかもしれません。でも、関係について知りたいのは「どの組 $(a, b)$ でその関係が成り立つか」だけです。それなら、成り立つ組を全部集めた集合を関係そのものだと考えればよいのです。第4章の「写像をグラフ（直積の部分集合）で定義する」のと同じ発想です。

<Example>
$X = \{1, 2, 3, 4\}$ 上の関係「$a$ は $b$ を割り切る」（$a \mid b$ と書く）は、

$$
\{(1,1), (1,2), (1,3), (1,4), (2,2), (2,4), (3,3), (4,4)\}
$$

という $X \times X$ の部分集合です。
</Example>

## 3つの性質

<Definition label="定義 5.2" title="反射律・対称律・推移律">
集合 $X$ 上の関係 $\sim$ について、

- **反射律**：すべての $a \in X$ について $a \sim a$
- **対称律**：すべての $a, b \in X$ について、$a \sim b$ ならば $b \sim a$
- **推移律**：すべての $a, b, c \in X$ について、$a \sim b$ かつ $b \sim c$ ならば $a \sim c$
</Definition>

<Example title="性質の比較">
いずれも整数全体 $\mathbb{Z}$ 上の関係とします（最後の行だけ人の集合）。

| 関係 | 反射律 | 対称律 | 推移律 |
| --- | :-: | :-: | :-: |
| $a = b$ | ○ | ○ | ○ |
| $a \le b$ | ○ | × | ○ |
| $a < b$ | × | × | ○ |
| $a \mid b$（$a$ は $b$ を割り切る） | ○ | × | ○ |
| $\lvert a - b \rvert \le 1$ | ○ | ○ | × |
| 「$a$ と $b$ は友達」 | ？ | ○ | × |

$\lvert a - b \rvert \le 1$ が推移律を満たさないのは、$0 \sim 1$、$1 \sim 2$ なのに $0 \not\sim 2$ だからです。「友達の友達は友達とは限らない」のと同じです。「友達」の反射律が「？」なのは、自分自身を自分の友達と数えるかどうかが決まっていないからです。日常の言葉を関係として扱うときは、このような点も定義で決めておく必要があります。
</Example>

<Pitfall title="性質が「成り立たない」ことは反例で示す">
3つの性質はすべて「すべての〜について」で始まります。成り立たないことを示すには、反例を**1つ**挙げれば十分です。たとえば $\le$ が対称律を満たさないことは、「$1 \le 2$ だが $2 \le 1$ ではない」で示せます。
</Pitfall>

## 同値関係

<Definition label="定義 5.3" title="同値関係">
反射律・対称律・推移律をすべて満たす関係を**同値関係**という。
</Definition>

同値関係は、「ある観点から見て同じ」を表す関係です。等号 $=$ が持っている性質のうち、この3つだけを取り出したものといえます。

### 代表例：合同式

<Definition label="定義 5.4" title="合同">
$n$ を自然数とする。整数 $a, b$ について、$a - b$ が $n$ の倍数であるとき、$a$ と $b$ は **$n$ を法として合同**であるといい、

$$
a \equiv b \pmod{n}
$$

と書く。
</Definition>

$a \equiv b \pmod{n}$ は「$a$ と $b$ を $n$ で割った余りが等しい」と同じ意味です（演習問題 5.2）。たとえば $17 \equiv 2 \pmod{5}$、$-3 \equiv 2 \pmod{5}$ です。時計の時刻は $12$ を法とした合同で考えています（15 時は 3 時）。

<Theorem label="定理 5.5">
$n$ を自然数とする。$\mathbb{Z}$ 上の関係 $a \equiv b \pmod{n}$ は同値関係である。
</Theorem>

<Proof>
3つの性質を順に確かめます。

**反射律：** $a - a = 0 = n \cdot 0$ は $n$ の倍数なので、$a \equiv a$。

**対称律：** $a \equiv b$ とすると、ある整数 $k$ で $a - b = nk$。すると $b - a = n \cdot (-k)$ も $n$ の倍数なので、$b \equiv a$。

**推移律：** $a \equiv b$ かつ $b \equiv c$ とすると、ある整数 $k, l$ で $a - b = nk$、$b - c = nl$。足すと $a - c = n(k + l)$ なので、$a \equiv c$。
</Proof>

同値関係であることを示すときは、このように**3つの性質を1つずつ**確かめます。

<Quiz id="relations-q01">
実数全体 $\mathbb{R}$ 上の次の関係のうち、**同値関係である**ものはどれ？

<Choice>$x \sim y \iff x \le y$</Choice>
<Choice>$x \sim y \iff \lvert x - y \rvert < 1$</Choice>
<Choice correct>$x \sim y \iff x - y \in \mathbb{Z}$</Choice>
<Choice>$x \sim y \iff xy > 0$</Choice>

<Explain>
3 番目は、$x - x = 0 \in \mathbb{Z}$（反射律）、$x - y \in \mathbb{Z}$ なら $y - x \in \mathbb{Z}$（対称律）、$x - y, y - z \in \mathbb{Z}$ なら和の $x - z \in \mathbb{Z}$（推移律）で、同値関係です。1 番目は対称律、2 番目は推移律（$0 \sim 0.6 \sim 1.2$ だが $0 \not\sim 1.2$）が成り立ちません。4 番目は、対称律と推移律は成り立ちますが、$0 \cdot 0 = 0$ で $0 \not\sim 0$ となるので反射律が成り立ちません（$\mathbb{R} \setminus \{0\}$ 上で考えれば同値関係になります。演習問題 5.1 と同じ形です）。
</Explain>
</Quiz>

## 同値類と商集合

同値関係があると、集合を「同じとみなせるもの」のグループに分けることができます。

<Definition label="定義 5.6" title="同値類と商集合">
集合 $X$ 上の同値関係 $\sim$ と $a \in X$ に対して、$a$ と同値な要素全体の集合

$$
[a] = \{\, x \in X \mid x \sim a \,\}
$$

を $a$ の**同値類**という。$a$ をこの同値類の**代表元**という。同値類全体の集合

$$
X / {\sim} = \{\, [a] \mid a \in X \,\}
$$

を $X$ の $\sim$ による**商集合**という。
</Definition>

<Example title="5 を法とする合同">
$\mathbb{Z}$ 上の $\equiv \pmod{5}$ について、

$$
\begin{aligned}
[0] &= \{\dots, -10, -5, 0, 5, 10, \dots\} \\
[1] &= \{\dots, -9, -4, 1, 6, 11, \dots\} \\
[2] &= \{\dots, -8, -3, 2, 7, 12, \dots\} \\
[3] &= \{\dots, -7, -2, 3, 8, 13, \dots\} \\
[4] &= \{\dots, -6, -1, 4, 9, 14, \dots\}
\end{aligned}
$$

で、商集合は $\mathbb{Z} / {\equiv} = \{[0], [1], [2], [3], [4]\}$ の **5 個の要素**からなります（$\mathbb{Z}/5\mathbb{Z}$ とも書きます）。$[7]$ は $[2]$ と同じ集合なので、新しい要素ではありません。
</Example>

商集合の要素は「同値類」という**集合**です。「同じとみなすものをひとまとめにした袋」を1つの要素として扱うのです。これにより、「余りが同じなら同じとみなす」という考え方を、集合として正確に表現できます。

<Theorem label="定理 5.7">
$\sim$ を集合 $X$ 上の同値関係とする。$a, b \in X$ について、

1. $a \in [a]$（特に同値類は空でない）
2. $a \sim b \iff [a] = [b]$
3. $[a] \ne [b]$ ならば $[a] \cap [b] = \varnothing$
</Theorem>

<Proof>
**1.** 反射律より $a \sim a$ なので、$a \in [a]$ です。

**2.** （$\Rightarrow$）$a \sim b$ とします。$x \in [a]$ ならば $x \sim a$ で、推移律より $x \sim b$、つまり $x \in [b]$。よって $[a] \subseteq [b]$。対称律より $b \sim a$ なので、同様に $[b] \subseteq [a]$。よって $[a] = [b]$。

（$\Leftarrow$）$[a] = [b]$ とします。1 より $a \in [a] = [b]$ なので $a \sim b$。

**3.** 対偶「$[a] \cap [b] \ne \varnothing$ ならば $[a] = [b]$」を示します。$x \in [a] \cap [b]$ とすると、$x \sim a$ かつ $x \sim b$。対称律より $a \sim x$、推移律より $a \sim b$。2 より $[a] = [b]$。
</Proof>

3つの性質（反射律・対称律・推移律）が、証明のどこで使われたかに注目しましょう。どれか1つでも欠けると、一般にはこの定理は成り立ちません（たとえば推移律を満たさない $\lvert a - b \rvert \le 1$ で同値類と同じ形の集合を作ると、$\{\, x \mid x \sim 0 \,\} = \{-1, 0, 1\}$ と $\{\, x \mid x \sim 1 \,\} = \{0, 1, 2\}$ は異なるのに重なってしまいます）。

### 同値関係と分割

定理 5.7 は、同値類たちが $X$ を**重なりなく、すき間なく**分けていることを示しています。

<Definition label="定義 5.8" title="分割">
集合 $X$ の空でない部分集合の集まり $\mathcal{A}$ が、次を満たすとき、$\mathcal{A}$ を $X$ の**分割**という。

1. $X$ のどの要素も、$\mathcal{A}$ のどれかの集合に属する（すき間がない）
2. $\mathcal{A}$ の異なる2つの集合は交わらない（重なりがない）
</Definition>

<Theorem label="定理 5.9" title="同値関係と分割の対応">
1. $\sim$ が $X$ 上の同値関係ならば、商集合 $X / {\sim}$ は $X$ の分割である。
2. 逆に、$\mathcal{A}$ が $X$ の分割ならば、「$a \sim b \iff a$ と $b$ は $\mathcal{A}$ の同じ集合に属する」で定めた関係 $\sim$ は同値関係であり、その商集合は $\mathcal{A}$ に一致する。
</Theorem>

<Proof>
**1.** 同値類は空でなく（定理 5.7 の 1）、どの $a \in X$ も $[a]$ に属し、異なる同値類は交わらない（定理 5.7 の 3）ので、分割の条件を満たします。

**2.** 反射律：$a$ は分割のどれかの集合に属するので、$a \sim a$。対称律：定義が $a, b$ について対称なので明らか。推移律：$a, b$ が集合 $A$ に、$b, c$ が集合 $B$ に属するとすると、$b \in A \cap B$ なので、分割の条件 2 より $A = B$。よって $a, c$ は同じ集合 $A$ に属し、$a \sim c$。

最後に、$a$ が属する分割の集合を $A$ とすると、$[a]$ は「$a$ と同じ集合に属する要素全体」なので $[a] = A$ です。よって商集合は $\mathcal{A}$ と一致します。
</Proof>

つまり、**「同値関係を決めること」と「集合をグループに分けること」は同じこと**です。クラス分けは「同じクラス」という同値関係を、余りによる分類は「合同」という同値関係を決めているのです。

<Quiz id="relations-q02">
$X = \{1, 2, 3, 4, 5, 6\}$ 上の同値関係「$a \sim b \iff a$ と $b$ を 3 で割った余りが等しい」の商集合は？

<Choice>$\{0, 1, 2\}$</Choice>
<Choice correct>$\{\{1, 4\}, \{2, 5\}, \{3, 6\}\}$</Choice>
<Choice>$\{\{1, 2, 3\}, \{4, 5, 6\}\}$</Choice>
<Choice>$\{[1], [2], [3], [4], [5], [6]\}$ で、6 個の要素を持つ</Choice>

<Explain>
余りが 1 のもの $\{1, 4\}$、余りが 2 のもの $\{2, 5\}$、余りが 0 のもの $\{3, 6\}$ の 3 つの同値類に分かれます。商集合の要素は同値類（集合）です。1 番目は余り（数）を並べたもので、同値類の集合ではありません。3 番目は大きさで分けたもので、余りの等しい $1$ と $4$ が別のグループに入っています。4 番目は書き方としては正しいのですが、$[1] = [4]$ などが同じ要素なので、要素の個数は 6 個ではなく 3 個です。
</Explain>
</Quiz>

## 代表元によらないこと（well-defined）

商集合の上で計算をするときには、注意が必要です。

$\mathbb{Z}/5\mathbb{Z}$ で足し算を $[a] + [b] = [a + b]$ と定めたいとします。ところが、同じ同値類にはいろいろな名前（代表元）があります。たとえば $[2] = [7]$、$[4] = [9]$ です。名前の付け方によって答えが変わってしまっては困ります。

- $[2] + [4] = [6]$
- $[7] + [9] = [16]$

$6 \equiv 16 \pmod 5$ なので $[6] = [16]$ で、一致しています。一般に次が成り立ちます。

<Theorem label="定理 5.10">
$a \equiv a'$ かつ $b \equiv b' \pmod{n}$ ならば、$a + b \equiv a' + b'$ かつ $ab \equiv a'b' \pmod{n}$。
</Theorem>

<Proof>
$a - a' = nk$、$b - b' = nl$ とおきます。$(a + b) - (a' + b') = n(k + l)$ なので、和は合同です。また

$$
ab - a'b' = a(b - b') + (a - a')b' = n(al + kb')
$$

なので、積も合同です。
</Proof>

この定理によって、$[a] + [b] = [a + b]$、$[a] \cdot [b] = [ab]$ は**代表元の選び方によらずに決まる**ことが分かります。このことを「**well-defined**（うまく定義されている）」といいます。

<Pitfall title="代表元によってしまう例">
$\mathbb{Z}/5\mathbb{Z}$ で「$[a]$ に $a$ を 3 で割った余りを対応させる」という規則を考えてみます。$[1] = [6]$ ですが、$1$ を 3 で割った余りは $1$、$6$ を 3 で割った余りは $0$ です。同じ要素に2つの値が対応してしまうので、これは**写像になりません**。商集合の上で何かを定義するときは、必ず well-defined かどうかを確かめましょう。
</Pitfall>

## 発展：有理数を作る

同値関係を使うと、整数から有理数を「作る」ことができます。

分数 $\frac{1}{2}$ と $\frac{2}{4}$ は、書き方は違っても同じ数です。そこで、整数の組 $(a, b)$（$b \ne 0$）で分数 $\frac{a}{b}$ を表すことにし、

$$
(a, b) \sim (c, d) \iff ad = bc
$$

という関係を考えます（$\frac{a}{b} = \frac{c}{d}$ の分母を払った形です）。これは $\mathbb{Z} \times (\mathbb{Z} \setminus \{0\})$ 上の同値関係になり（演習問題 5.4）、その同値類を**有理数**と定義します。$(1, 2)$、$(2, 4)$、$(-3, -6)$ はすべて同じ同値類 = 同じ有理数 $\frac12$ です。

足し算は $[(a, b)] + [(c, d)] = [(ad + bc, bd)]$ と定め、これが代表元によらないことを確かめれば、有理数の計算がすべて集合と同値関係から組み立てられます。「数とは何か」を集合論で答える、大学数学らしい考え方の一つです。

## 演習問題

<Exercise level={1} label="問 5.1">
$\mathbb{Z} \setminus \{0\}$ 上の関係「$a \sim b \iff ab > 0$」が同値関係であることを示し、商集合を求めよ。

<Reveal>
反射律：$a \ne 0$ なので $a^2 > 0$。対称律：$ab > 0 \Rightarrow ba > 0$。推移律：$ab > 0$ かつ $bc > 0$ とすると、$ab \cdot bc = ac \cdot b^2 > 0$ で $b^2 > 0$ なので $ac > 0$。

$a \sim b$ は「$a$ と $b$ の符号が同じ」という意味なので、商集合は $\{\{\text{正の整数}\}, \{\text{負の整数}\}\} = \{[1], [-1]\}$ です。
</Reveal>
</Exercise>

<Exercise level={2} label="問 5.2">
$n$ を自然数とする。整数 $a, b$ について、$a \equiv b \pmod{n}$ であることと、$a$ と $b$ を $n$ で割った余りが等しいことは同値であることを示せ。

<Reveal kind="hint">
$a = nq_1 + r_1$、$b = nq_2 + r_2$（$0 \le r_1, r_2 < n$）とおきます。$r_1 - r_2$ がとりうる範囲を考えましょう。
</Reveal>

<Reveal>
$a = nq_1 + r_1$、$b = nq_2 + r_2$（$q_1, q_2$ は整数、$0 \le r_1, r_2 < n$）とおくと、$a - b = n(q_1 - q_2) + (r_1 - r_2)$ です。

（$\Leftarrow$）$r_1 = r_2$ ならば $a - b = n(q_1 - q_2)$ は $n$ の倍数です。

（$\Rightarrow$）$a - b$ が $n$ の倍数ならば、$r_1 - r_2 = (a - b) - n(q_1 - q_2)$ も $n$ の倍数です。ところが $-n < r_1 - r_2 < n$ なので、この範囲にある $n$ の倍数は $0$ だけです。よって $r_1 = r_2$ です。
</Reveal>
</Exercise>

<Exercise level={2} label="問 5.3">
平面上の点全体 $\mathbb{R}^2$ 上で、「$(x_1, y_1) \sim (x_2, y_2) \iff x_1^2 + y_1^2 = x_2^2 + y_2^2$」と定める。これが同値関係であることを確かめ、同値類を図形として説明せよ。

<Reveal>
「$x^2 + y^2$ の値が等しい」という関係なので、等号の性質から反射律・対称律・推移律がすぐに分かります。

点 $(a, b)$ の同値類は、原点からの距離が $\sqrt{a^2 + b^2}$ に等しい点の集合、つまり**原点を中心とする半径 $\sqrt{a^2 + b^2}$ の円**です（$(0, 0)$ の同値類は原点だけ）。平面は、原点を中心とする同心円たちに分割されます。

一般に、写像 $f \colon X \to Y$ に対して「$a \sim b \iff f(a) = f(b)$」と定めると同値関係になります。この問題は $f(x, y) = x^2 + y^2$ の場合です。
</Reveal>
</Exercise>

<Exercise level={3} label="問 5.4">
$\mathbb{Z} \times (\mathbb{Z} \setminus \{0\})$ 上の関係「$(a, b) \sim (c, d) \iff ad = bc$」が同値関係であることを示せ。

<Reveal kind="hint">
推移律が本題です。$ad = bc$ と $cf = de$ から $af = be$ を導きます。両辺に $d$（$\ne 0$）を掛けたものを考えましょう。
</Reveal>

<Reveal>
**反射律：** $ab = ba$ なので $(a, b) \sim (a, b)$。

**対称律：** $ad = bc$ ならば $cb = da$ なので $(c, d) \sim (a, b)$。

**推移律：** $(a, b) \sim (c, d)$、$(c, d) \sim (e, f)$ とすると、$ad = bc$、$cf = de$ です。このとき

$$
afd = (ad)f = bcf = b(cf) = bde = bed
$$

なので $(af - be)d = 0$。$d \ne 0$ なので $af = be$、つまり $(a, b) \sim (e, f)$ です。

（最後に $d \ne 0$ で割ったところで、第2成分が 0 でないという条件が効いています。第2成分に 0 を許すと、$(1, 0) \sim (0, 0) \sim (2, 1)$ なのに $(1, 0) \not\sim (2, 1)$ となって推移律が壊れます。）
</Reveal>
</Exercise>

## まとめ

- 集合 $X$ 上の**関係**は、$X \times X$ の部分集合。
- **反射律・対称律・推移律**をすべて満たす関係が**同値関係**。成り立たないことは反例1つで示す。
- 同値類 $[a]$ は「$a$ と同じとみなすもの全体」、商集合 $X/{\sim}$ は同値類全体の集合。
- 異なる同値類は交わらない。**同値関係と分割は1対1に対応**する。
- 商集合の上で演算や写像を定めるときは、**代表元によらない（well-defined）**ことを確かめる。
