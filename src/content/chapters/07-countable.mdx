## 数えずに比べる

教室にいる生徒の数と椅子の数、どちらが多いでしょう？ 数えて比べるのが普通ですが、数えなくても比べる方法があります。**全員に座ってもらう**のです。全員が座れて空席もなければ、生徒と椅子は同じ数です。

これは、生徒の集合から椅子の集合への**全単射**を作ったことにほかなりません。この考え方なら、「何個あるか」を数えられない無限集合でも、大きさを比べることができます。

<Definition label="定義 7.1" title="濃度が等しい">
集合 $A$ から $B$ への全単射が存在するとき、$A$ と $B$ は**濃度が等しい**（または対等である）といい、$\lvert A \rvert = \lvert B \rvert$ と書く。
</Definition>

$\lvert A \rvert$ を $A$ の**濃度**と呼びます。有限集合では、濃度が等しいことと要素の個数が等しいことは同じです。

<Theorem label="定理 7.2">
どんな集合 $A, B, C$ についても、

1. $\lvert A \rvert = \lvert A \rvert$
2. $\lvert A \rvert = \lvert B \rvert$ ならば $\lvert B \rvert = \lvert A \rvert$
3. $\lvert A \rvert = \lvert B \rvert$ かつ $\lvert B \rvert = \lvert C \rvert$ ならば $\lvert A \rvert = \lvert C \rvert$
</Theorem>

<Proof>
1. 恒等写像 $\mathrm{id}_A$ は全単射です。
2. 全単射 $f \colon A \to B$ には逆写像 $f^{-1} \colon B \to A$ があり、これも全単射です（定理 4.9）。
3. 全単射 $f \colon A \to B$、$g \colon B \to C$ の合成 $g \circ f \colon A \to C$ は全単射です（定理 4.7）。
</Proof>

これは同値関係の3つの性質と同じ形です。（「すべての集合の集合」は考えられないので（第10章）、厳密には「同値関係」とは呼びませんが、同じように扱えます。）

## 部分が全体と同じ大きさ

<Example title="ガリレオのパラドックス">
自然数全体 $\mathbb{N} = \{1, 2, 3, \dots\}$ と、正の偶数全体 $E = \{2, 4, 6, \dots\}$ を比べます。

$$
f \colon \mathbb{N} \to E, \qquad f(n) = 2n
$$

は全単射です（単射：$2m = 2n \Rightarrow m = n$。全射：偶数 $2k$ には $k$ が移る）。よって $\lvert \mathbb{N} \rvert = \lvert E \rvert$ です。
</Example>

$E$ は $\mathbb{N}$ の一部分（真部分集合）なのに、同じ大きさです。有限集合では決して起こらないことです（鳩の巣原理）。17 世紀のガリレオはこれを奇妙に思い、「無限について大小を語るのは無意味だ」と結論しました。しかし 19 世紀のカントールは逆に、**これこそが無限の特徴だ**と考えました。

この不思議さを体感できるのが、数学者ヒルベルトが考えた「無限ホテル」の話です。

<HilbertHotel client:visible />

「1人来た」場面の移動は $n \mapsto n + 1$、「無限に来た」場面は元の客を $n \mapsto 2n$、新しい客を $k \mapsto 2k - 1$ に移しています。どちらの規則でも、各客は1つの部屋に入り、各部屋には1人ずつ入ります。これを全単射として式で確かめることが、図に代わる**証明**です。

<Note title="無限集合の定義">
集合 $A$ が**有限**であるとは、ある $n \ge 0$ について $\{1, 2, \dots, n\}$ と濃度が等しい（$n = 0$ のときは $A = \varnothing$）ことをいいます。有限でない集合を**無限**集合といいます。
</Note>

## 可算集合

<Definition label="定義 7.3" title="可算集合">
自然数全体 $\mathbb{N}$ と濃度が等しい集合を**可算無限集合**という。その濃度を $\aleph_0$（アレフ・ゼロ）で表す。有限集合または可算無限集合であることを**高々可算**という。
</Definition>

<Note title="用語の流儀">
本によっては、「可算」を「可算無限」の意味で使ったり、「高々可算」の意味で使ったりします。このサイトでは「可算 = 可算無限」とし、有限も含めるときは「高々可算」と書きます。
</Note>

$A$ が可算無限であるとは、全単射 $f \colon \mathbb{N} \to A$ があること、つまり $A$ の要素を

$$
f(1),\ f(2),\ f(3),\ \dots
$$

と、**もれなく・重複なく、1列に並べられる**ことです。

<Theorem label="定理 7.4">
整数全体 $\mathbb{Z}$ は可算である。
</Theorem>

<Proof>
整数を $0, 1, -1, 2, -2, 3, -3, \dots$ と並べます。式で書くと、

$$
f(n) = \begin{cases} \dfrac{n}{2} & (n \text{ が偶数}) \\[2mm] -\dfrac{n - 1}{2} & (n \text{ が奇数}) \end{cases}
$$

です（$f(1) = 0$、$f(2) = 1$、$f(3) = -1$、$f(4) = 2$、…）。

**単射：** 偶数 $n$ の行き先は正の整数、奇数 $n$ の行き先は $0$ 以下の整数なので、偶数と奇数の行き先は重なりません。偶数どうしなら $\frac{m}{2} = \frac{n}{2} \Rightarrow m = n$、奇数どうしなら $-\frac{m-1}{2} = -\frac{n-1}{2} \Rightarrow m = n$。

**全射：** 正の整数 $k$ には $f(2k) = k$、$0$ 以下の整数 $-k$（$k \ge 0$）には $f(2k + 1) = -k$ が移ります。
</Proof>

<Pitfall title="並べ方が悪いと失敗する">
「$0, 1, 2, 3, \dots$ と並べて、それから $-1, -2, -3, \dots$」という並べ方では、正の整数が無限に続くので、いつまでたっても $-1$ の番が来ません。$-1$ に番号が付かないので、これは $\mathbb{N}$ からの全単射になりません。**どの要素にも、有限の番号が付く**ように並べることが大切です。
</Pitfall>

### 自然数の組も可算

<Theorem label="定理 7.5">
$\mathbb{N} \times \mathbb{N}$ は可算である。
</Theorem>

<Proof>
自然数の組 $(m, n)$ を表の形に並べ、**$m + n$ が小さい順**（斜めの線ごと）に、同じ線の中では $m$ が小さい順に番号を付けます。

| | $n = 1$ | $n = 2$ | $n = 3$ | $n = 4$ | $\cdots$ |
| --- | :-: | :-: | :-: | :-: | :-: |
| $m = 1$ | **1** | **2** | **4** | **7** | |
| $m = 2$ | **3** | **5** | **8** | | |
| $m = 3$ | **6** | **9** | | | |
| $m = 4$ | **10** | | | | |
| $\vdots$ | | | | | |

$m + n = s$ の線には $s - 1$ 個の組があり、それより前の線には合計 $1 + 2 + \cdots + (s - 2) = \frac{(s-1)(s-2)}{2}$ 個の組があります。よって組 $(m, n)$ の番号は

$$
\pi(m, n) = \frac{(m + n - 1)(m + n - 2)}{2} + m
$$

です。どの組も、ある有限の線の上にあり、その線の中でちょうど1つの番号を持ちます。また、番号 $1, 2, 3, \dots$ は線の順・線の中の順に1つずつ使われるので、どの番号にもちょうど1つの組が対応します。よって $\pi$ は全単射です。
</Proof>

表を横に（$m = 1$ の行を全部数えてから $m = 2$ の行へ）数えると、1 行目が終わらないので失敗します。**斜めに数える**のがポイントです。この「対角線に沿って数える」アイデアは、第8章の「対角線論法」とは別物なので注意しましょう。

<Explain>
$m + n = 5$ なので、$\pi(2, 3) = \frac{4 \cdot 3}{2} + 2 = 8$ です。表でも、$m = 2$、$n = 3$ の位置は 8 になっています。$m + n = 5$ の線には $(1,4), (2,3), (3,2), (4,1)$ が並び、番号は 7, 8, 9, 10 です。
</Explain>
</Quiz>

## 可算性を示す便利な道具

毎回ぴったりの全単射を作るのは大変です。次の定理を使うと、ずっと楽になります。

<Theorem label="定理 7.6">
1. $\mathbb{N}$ の部分集合は、高々可算である。
2. 集合 $A$ から $\mathbb{N}$ への単射があれば、$A$ は高々可算である。
3. $A$ が空でなく、$\mathbb{N}$ から $A$ への全射があれば、$A$ は高々可算である。
</Theorem>

<Proof>
**1.** $S \subseteq \mathbb{N}$ とします。$S$ が有限なら終わりです。$S$ が無限のとき、$S$ の要素を**小さい順**に $s_1 < s_2 < s_3 < \cdots$ と並べます。具体的には、$s_1$ を $S$ の最小元、$s_2$ を $S \setminus \{s_1\}$ の最小元、…と定めます（自然数の空でない部分集合には必ず最小元があり、$S$ は無限なので、この操作は終わりません）。$n \mapsto s_n$ は狭義単調増加なので単射です。また $S$ のどの要素 $s$ も、自分より小さい $S$ の要素が有限個（$s - 1$ 個以下）しかないので、有限の番号で現れます。よって全単射です。

**2.** 単射 $g \colon A \to \mathbb{N}$ があると、$A$ と $g(A)$ の濃度が等しく、$g(A)$ は $\mathbb{N}$ の部分集合なので、1 より高々可算です。

**3.** 全射 $h \colon \mathbb{N} \to A$ があるとします。各 $a \in A$ について、$h(n) = a$ となる $n$ のうち**最小のもの**を $g(a)$ とすると、$g \colon A \to \mathbb{N}$ は単射です（$g(a) = g(b)$ なら $a = h(g(a)) = h(g(b)) = b$）。2 より $A$ は高々可算です。
</Proof>

3 の証明では、$a$ に移る自然数がたくさんあっても「最小のもの」という**ルールで1つに決めて**いることに注目しましょう。この点は、この章の最後で大事になります。

<Example title="単射を作るだけでよい">
$\mathbb{N} \times \mathbb{N}$ から $\mathbb{N}$ への写像 $(m, n) \mapsto 2^m 3^n$ は単射です（素因数分解の一意性より）。これだけで、定理 7.6 の 2 から $\mathbb{N} \times \mathbb{N}$ が高々可算、無限集合なので可算と分かります。定理 7.5 のような番号の式を求めなくてよいのです。
</Example>

## 有理数も可算

有理数は数直線上にびっしり詰まっています。どんな2つの有理数の間にも、無限に多くの有理数があります。それでも、有理数の「個数」は自然数と同じなのです。

<Theorem label="定理 7.7">
有理数全体 $\mathbb{Q}$ は可算である。
</Theorem>

<Proof>
まず正の有理数を並べます。正の有理数は $\frac{p}{q}$（$p, q \in \mathbb{N}$）と書けるので、定理 7.5 の表で $(p, q)$ の位置に $\frac{p}{q}$ を置き、斜めに読んでいきます。ただし、**すでに出てきた数と同じ値の分数は飛ばします**。

$$
\frac11,\ \frac12,\ \frac21,\ \frac13,\ \cancel{\tfrac22},\ \frac31,\ \frac14,\ \frac23,\ \frac32,\ \frac41,\ \frac15,\ \cancel{\tfrac24},\ \cancel{\tfrac33},\ \cancel{\tfrac42},\ \frac51,\ \dots
$$

（$\frac22 = \frac11$、$\frac24 = \frac12$ などが飛ばされます。）どの正の有理数も、既約分数 $\frac{p}{q}$ の位置で最初に現れるので、有限の番号が付きます。重複は飛ばしているので、各数に番号はちょうど1つです。こうして正の有理数の列 $r_1, r_2, r_3, \dots$ ができます。

あとは定理 7.4 と同じように、$0, r_1, -r_1, r_2, -r_2, \dots$ と並べれば、$\mathbb{Q}$ 全体がもれなく重複なく1列に並びます。
</Proof>

重複を飛ばす代わりに、定理 7.6 を使うこともできます。$\mathbb{Z} \times \mathbb{N}$ は可算で（演習問題 7.3）、$(p, q) \mapsto \frac{p}{q}$ は $\mathbb{Z} \times \mathbb{N}$ から $\mathbb{Q}$ への全射なので、$\mathbb{Q}$ は高々可算です。無限集合なので可算です。

全単射 $f \colon \mathbb{N} \to \mathbb{Z}$（定理 7.4）を使うと $(m, n) \mapsto (f(m), f(n))$ が $\mathbb{N} \times \mathbb{N}$ から $\mathbb{Z} \times \mathbb{Z}$ への全単射になるので、$\mathbb{Z} \times \mathbb{Z}$ は可算です。同じ考え方で、$\mathbb{Z} \times \mathbb{Z} \times \mathbb{Z} = (\mathbb{Z} \times \mathbb{Z}) \times \mathbb{Z}$ も可算です。残りの3つは、第8章で**可算でない**ことを証明します。可算でない無限集合があるということが、次の章の主題です。
</Explain>
</Quiz>

## 可算集合の可算和

<Theorem label="定理 7.8">
$A_1, A_2, A_3, \dots$ がどれも可算集合で、それぞれの列挙 $A_i = \{a_{i1}, a_{i2}, a_{i3}, \dots\}$ が**与えられている**とする。このとき $\displaystyle\bigcup_{i \in \mathbb{N}} A_i$ は可算である。
</Theorem>

<Proof>
$(i, j) \mapsto a_{ij}$ は $\mathbb{N} \times \mathbb{N}$ から $\bigcup_i A_i$ への全射です（和集合のどの要素も、ある $A_i$ の $j$ 番目として現れる）。$\mathbb{N} \times \mathbb{N}$ は可算なので、$\mathbb{N}$ から $\bigcup_i A_i$ への全射があり、定理 7.6 の 3 より高々可算です。$A_1$ が無限なので、和集合も無限で、可算です。
</Proof>

<Example>
$A_n = \left\{\, \frac{m}{n} \;\middle|\; m \in \mathbb{Z} \,\right\}$（分母が $n$ の分数全体）とすると、各 $A_n$ は $\mathbb{Z}$ の列挙から具体的に列挙でき、$\mathbb{Q} = \bigcup_n A_n$ です。これも $\mathbb{Q}$ が可算であることの証明になります。
</Example>

<Note title="発展：列挙を「選ぶ」ことと選択公理">
定理 7.8 では、各 $A_i$ の列挙が**あらかじめ与えられている**と仮定しました。では、「各 $A_i$ が可算である（列挙が**存在する**）」ことしか分かっていない場合はどうでしょう。

その場合、証明を始める前に、無限個の $A_i$ のそれぞれについて、無数にある列挙の中から**1つずつ選ぶ**必要があります。上の例のように具体的な列挙が書ければ問題ありませんが、一般にはそのような選び方のルールがありません。実は、無限個の集合から1つずつ同時に選べることは、集合論の基本的な公理からは導けず、**選択公理**（の弱い形である可算選択公理）という別の公理が必要になります。実際、選択公理を除いた公理だけでは「可算集合の可算和は可算」を証明できないことが知られています。

通常の大学数学では選択公理を認めるので、「可算集合の可算和は可算」は定理として使われます。このことは[第10章](../choice/)で改めて扱います。それまでは、「列挙を選ぶ操作が隠れている」ことだけ覚えておいてください。
</Note>

## 演習問題

<Exercise level={1} label="問 7.1">
次の集合の組が、濃度が等しいことを全単射を作って示せ。

1. $\mathbb{N}$ と $\{3, 4, 5, 6, \dots\}$
2. $\mathbb{N}$ と 奇数の自然数全体 $\{1, 3, 5, \dots\}$
3. 開区間 $(0, 1)$ と開区間 $(0, 5)$

<Reveal>
1. $n \mapsto n + 2$。逆写像は $m \mapsto m - 2$ なので全単射です。
2. $n \mapsto 2n - 1$。逆写像は $m \mapsto \frac{m + 1}{2}$。
3. $x \mapsto 5x$。逆写像は $y \mapsto \frac{y}{5}$。

3 のように、長さの違う区間でも濃度は等しくなります。「長さ」と「濃度」は別の大きさです。
</Reveal>
</Exercise>

<Exercise level={2} label="問 7.2">
可算集合 $A$ と有限集合 $B$ の和集合 $A \cup B$ は可算であることを示せ。

<Reveal kind="hint">
ヒルベルトホテルの「1人来た」をくり返します。$B \setminus A$ の要素を先に並べ、そのあとに $A$ の列挙を続けましょう。
</Reveal>

<Reveal>
$B \setminus A = \{b_1, \dots, b_k\}$（互いに異なる）とし、$A$ の列挙を $a_1, a_2, \dots$ とします。

$$
b_1, \dots, b_k, a_1, a_2, a_3, \dots
$$

と並べると、$A \cup B$ の要素がもれなく重複なく並びます（$b_i$ はどれも $A$ に属さないので、$a_j$ と重ならない）。式で書けば、$n \le k$ なら $n \mapsto b_n$、$n > k$ なら $n \mapsto a_{n - k}$ が全単射です。
</Reveal>
</Exercise>

<Exercise level={2} label="問 7.3">
$\mathbb{Z} \times \mathbb{N}$ が可算であることを示せ。

<Reveal>
全単射 $f \colon \mathbb{N} \to \mathbb{Z}$（定理 7.4）を使うと、$(m, n) \mapsto (f(m), n)$ は $\mathbb{N} \times \mathbb{N}$ から $\mathbb{Z} \times \mathbb{N}$ への全単射です。$\mathbb{N} \times \mathbb{N}$ は可算（定理 7.5）なので、$\mathbb{Z} \times \mathbb{N}$ も可算です。
</Reveal>
</Exercise>

<Exercise level={3} label="問 7.4">
整数係数の多項式全体の集合 $\mathbb{Z}[x]$ は可算であることを示せ。

<Reveal kind="hint">
次数が $d$ 以下の多項式全体 $P_d$ は、係数の組 $(a_0, a_1, \dots, a_d) \in \mathbb{Z}^{d+1}$ と1対1に対応します。$\mathbb{Z}^{d+1}$ が可算なことは帰納法で示せます。そのあと定理 7.8 を使います。
</Reveal>

<Reveal>
$\mathbb{Z}^{k}$（$\mathbb{Z}$ の $k$ 個の直積）が可算であることを $k$ についての帰納法で示します。$k = 1$ は定理 7.4。$\mathbb{Z}^k$ が可算なら、$\mathbb{Z}^{k+1} = \mathbb{Z}^k \times \mathbb{Z}$ は「可算集合 × 可算集合」で、全単射を使って $\mathbb{N} \times \mathbb{N}$ と対応させられるので可算です。

次数が $d$ 以下の多項式全体 $P_d$ は、$a_0 + a_1 x + \cdots + a_d x^d \mapsto (a_0, \dots, a_d)$ で $\mathbb{Z}^{d+1}$ と全単射の関係にあるので可算です。$P_d$ の列挙は、$\mathbb{Z}^{d+1}$ の具体的な列挙（帰納法の中で、定理 7.4 と 7.5 の式から作れる）から具体的に得られます。よって定理 7.8 より、$\mathbb{Z}[x] = \bigcup_{d \ge 0} P_d$ は可算です。

（各 $P_d$ の列挙を具体的に作れるので、この証明では選択公理は必要ありません。さらに、0 でない多項式の根は有限個なので、0 でない整数係数の多項式の根になる複素数（**代数的数**）全体も可算です。）
</Reveal>
</Exercise>

## まとめ

- 2つの集合の間に全単射があるとき、**濃度が等しい**という。数えずに比べる方法。
- 無限集合は、自分の真部分集合と濃度が等しくなりうる（$\mathbb{N}$ と偶数全体、ヒルベルトホテル）。
- $\mathbb{N}$ と濃度が等しい集合が**可算集合**。「もれなく・重複なく1列に並べられる」こと。
- $\mathbb{Z}$、$\mathbb{N} \times \mathbb{N}$、$\mathbb{Q}$ は可算。$\mathbb{N}$ への単射、または $\mathbb{N}$ からの全射があれば高々可算。
- 列挙が与えられた可算集合の可算和は可算。列挙を**選ぶ**必要があるときは、選択公理が関わる。

では、可算でない無限集合はあるのでしょうか？ 次の章で、その答えを証明します。
